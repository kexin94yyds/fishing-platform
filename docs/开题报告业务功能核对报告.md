## 4. 边界和文字偏差

1. 老师后续确认增加一个登录钓友预约页，但系统仍未实现商品商城、购物车、自助注册、在线支付、自动会员升级/积分兑换/充值折扣、鱼获自动识别、GIS/物联网、第三方支付回调、线上退款和自动对账。这些是**有意排除的超范围功能**，不是缺陷。

2. 开题报告实施方案写为 `MyBatisPlus + Element UI`，项目实际为 `MyBatis + Element Plus`。业务逻辑不受影响，但答辩材料应统一技术名称。
3. 参考文献第 20 条是药品审批与临床试验研究，与本课题关联度低。该问题属于报告文字质量，不影响平台功能完整性。
4. Windows 一键启停脚本已完成静态代码核对，但当前验收机为 macOS，未在 Windows 10/11 上再次实机执行。
5. MySQL 8.4.11 实库迁移和业务链路已通过；Flyway 运行时会提示当前版本官方最新测试到 MySQL 8.1，因此正式环境仍建议在目标 MySQL 版本执行一次迁移回归。

## 5. 登录钓友单页扩展合同

1. 管理员创建 `USER` 账号；第一版不开放钓友自助注册。
2. USER 登录后只进入 `/my-fishing`，后台接口对 USER 返回 403；工作人员也不能访问 `/api/user/**`。
3. 钓友可查看开放钓位、余量和价格，提交预约后只查看/取消本人未来预约；姓名、所有者、价格、容量和收款记录由服务端确定。
4. 用户预约直接进入原管理端，由工作人员继续收款、结单、爽约和渔获登记。
5. 验收结果：后端 89 项、前端 lint/typecheck/build、MySQL 8.4.11 新库与带历史碰撞数据的 V12→V13 升级、真实 USER HTTP 业务链全部通过。
